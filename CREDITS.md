# 来源与许可 · Sources and licences

## 地图与程序 · Maps and code

- 《华夏乐踪》是 DeanChensj 的《江山时序》的衍生项目。程序、上游历史政权图层和晕渲图沿用 GPL-3.0，详见 [许可证](LICENSE)。上游对照提交为 `f628e2d573b83c7f312faae6fa075b649893d9d7`。[江山时序](https://github.com/DeanChensj/jiangshan-map)
- Echoes Across China is a derivative of DeanChensj’s Jiangshan Atlas. The code, upstream polity outlines and rendered relief images are under GPL-3.0. The upstream reference is `f628e2d573b83c7f312faae6fa075b649893d9d7`. [Jiangshan Atlas](https://github.com/DeanChensj/jiangshan-map), [Licence](LICENSE)
- 历史政权轮廓由上游依据史料调整，早期底图资料来自 historical-basemaps。边界为分期示意。历史城市和现代城市名称用作位置参照。[historical-basemaps](https://github.com/aourednik/historical-basemaps)
- Upstream adjusted polity outlines against historical sources, drawing initially on historical-basemaps. Boundaries are schematic for the displayed phase. Historical and modern city names provide location reference. [historical-basemaps](https://github.com/aourednik/historical-basemaps)
- 河流、湖泊及晕渲所用高程来自公有领域资料。高程包括 SRTM、GMTED2010 和 ETOPO1。发布包使用保留政权轮廓的快照，排除 CHGIS V6、Hartwell 州府边界和 DataV 现代省界。[上游地图源说明](https://github.com/DeanChensj/jiangshan-map/blob/f628e2d573b83c7f312faae6fa075b649893d9d7/data/atlas/README.md), [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)
- Public-domain sources provide the hydrography and relief elevations, including SRTM, GMTED2010 and ETOPO1. The staged site uses polity snapshots with the CHGIS V6 and Hartwell prefecture data and DataV modern provinces excluded. [Upstream map provenance](https://github.com/DeanChensj/jiangshan-map/blob/f628e2d573b83c7f312faae6fa075b649893d9d7/data/atlas/README.md), [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)
