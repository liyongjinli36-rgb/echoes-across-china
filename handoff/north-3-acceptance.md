仓库、可达 Git 历史和课程材料目录中未找到独立的《地区地图制作标准》正文。本轮逐项执行任务清单给出的验收路线，并以项目校验器和现有六栏样卡核对数据约束。[项目校验器](../scripts/check_music_atlas.cjs) · [六栏样卡](dragon-drum/station.md)

## 关闭卡片、切区与空结果返回

- 在北方播放《流水》后点卡片关闭，播放器暂停并清除音源，北方按钮仍选中。重新起播后分别测了北方 → 华东与华中（《小黄马》）、北方 → 华南与西南（《流水》）、北方 → 全国总览（《小黄马》）。24 次关闭或切换均使旧音暂停，400 毫秒后旧时钟无推进，央视视频元素也已移出页面。
- 北方默认“全部时期”可找到年代待考的信天游、河北花调和快板。先选秦朝可见历史证据“秦陵百戏俑”。在图层仅保留民歌、器乐独奏、器乐合奏、说唱、戏曲五个类别后，标记、列表和试听项都为零，出现“当前范围内暂无匹配曲目。”／“No works match the current filters.”。
- 点“返回全部时期”／“Show all periods”后仍在北方，保留类别筛选并恢复 29 项列表和 22 个试听项，三首年代待考曲目重新出现。重新勾选全部类别恢复北方 58 项。

## 11 月 27 日主控修复复测

本地服务仅提供新打包的 `dist/`。工作区、发布目录及 HTTP 返回的 JS、CSS 分别按 SHA-256 比对一致。浏览器为无头 Google Chrome 158.0.8127.88。以下是本次三项专项复测，前文的全站数据来自 11 月 26 日。

### 英文展开侧栏与地图按钮

对每个可见控件调用 `document.elementFromPoint` 检查中心落点，再向同一坐标发送触屏轻触或鼠标点击，读取实际触发的控件和页面变化。三个视口均测全国总览、全国秦朝和北方全部时期。320 × 568 另在作品栏滚动 180 px 后重复点击。

| 控件 | 实际点击结果 |
| --- | --- |
| `#zoom-in`、`#zoom-out`、`#act-reset-camera` | 放大后 SVG 的 `viewBox` 变窄，缩小后变宽。复位、缩放、再复位，两次复位得到相同的 `viewBox`。三个场景均通过。 |
| Contemporary polities | 全国秦朝视图点击图例文字可展开，再点可收起。320 视口下可点击标题和缩小键的各 81 个采样点均命中自身。两者外框装饰边缘约有 4 px 交叠。 |
| Class listening | 三个场景均命中原生菜单，可选曲打开《信天游》卡片。另选《流水》时，卡片标题和网址中的曲目 ID 均正确。 |
| Heritage、Compare regions | 全国总览和全国秦朝下，分别打开非遗名录与区域比较面板。北方子地图按现有设计隐藏这两个全国入口，课堂试听和地图按钮均可操作。 |

原先的地图按钮中心误开 Heritage、秦朝图例误开 Compare regions 均未复现。320 与 390 像素宽的英文全国工具栏单行显示，Compare regions 中心可直接点开。其右端初始分别裁切约 25 px 和 14 px。单指左滑工具栏后，两个视口实点按钮右缘内侧 2 px 均能打开区域比较。三种视口的页面宽度分别为 320、390、1366 px，均与所设视口一致。

### 《小黄马》视频焦点空格键

在北方全部时期打开《小黄马》，将焦点置于原生 `<video>` 后按两次空格。首按从选段起点 28 秒出声，再按暂停。六次按键的目标都是同一张卡片的 `VIDEO`，浏览器标记为可信键盘事件。时间轴播放键全程保持 `aria-pressed="false"`，地区、时期、年份、曲目和 URL 均保持原值。初验时约 1.4 秒后跳去《流水》的现象已消失。

### 兴国山歌零起点选段截停与重播

从华东与华中曲目列表打开黄训国《打支山歌过横排》。央视原片长 129.72 秒，站内配置 `originalRangeSeconds: [0, 30]`。初验时曾自然播至 34.06 秒。此次点原生播放键后将进度移至约 26 秒，随后保持正常速度自然播放。三次均自动暂停，再点原生播放键均触发从 0.000 秒开始的重播。
